# Windows Utilities & Tools

Repositório de ferramentas, utilitários e automações de alta performance para **Windows 11**, desenvolvido para o ecossistema de **Eduardo Noé (`eduardonoe`)**.

---

## 🚀 Ferramentas Disponíveis

### 📡 [NetMonitor](NetMonitor/)
Monitor de tráfego de rede ultraleve integrado diretamente à barra de tarefas do Windows 11.
* **Mede em Bits Reais (Mbps e Gbps):** Equivalente à medição contratada de provedores de internet.
* **Ultraleve:** ~10 MB de RAM e 0.00% de CPU em C# Win32 nativo.
* **Alinhamento Tabular Rígido:** Eixo numérico e unidades alinhadas sem oscilação horizontal.
* **Suporte Multi-monitor:** Projetado para funcionar com múltiplos monitores verticais ou horizontais.
* **Instalável e Portátil:**
  * 🌟 **Instalador Oficial:** Assistente com tema dark, seleção de idioma (Português/Inglês) e integração com o sistema.
  * 💼 **NetMonitor Portable:** Versão que dispensa instalação e roda direto de pendrive ou pasta.
